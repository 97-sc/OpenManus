# OpenManus Web UI（二次开发 Direction 2）可选依赖
#
# 安装方式：
#   pip install -r requirements-webui.txt
#
# 本文件已通过 -r 引用主依赖，可单独安装。
#
# ---------------------------------------------------------------------------
# 为什么单独成文件，而不是并入 requirements.txt
# ---------------------------------------------------------------------------
# gradio 4.31.0 发布于 2024-06，其依赖链要求较旧版本的 starlette / anyio。
# 为让 Web UI 能启动，本文件把这两个包显式钉在低版本，代价是打破了主干依赖：
#
#   fastapi 0.141.1 要求 starlette>=0.46.0  -> 被钉在 0.40.0
#   mcp 1.5.0       要求 anyio>=4.5         -> 被钉在 4.4.0
#
# 即：安装本文件后 `pip check` 会报告上述冲突，这是预期内、已知的代价。
# 若只使用命令行 Agent（python main.py）、不需要 Web UI，
# 请不要安装本文件，保持 requirements.txt 的主干依赖完整。
#
# 根因是 gradio 4.31.0 版本过旧（当时选它，是因为 gradio 6.x 存在 localhost
# 可达性检查问题）。升级到 4.44.x / 5.x 可解除上述冲突，但需同步调整
# web_ui.py 中 ChatInterface 的调用方式，属独立改动，尚未实施。
# ---------------------------------------------------------------------------

-r requirements.txt

gradio==4.31.0
starlette==0.40.0
anyio==4.4.0
